# About me
I am an analytics engineer on the RevOps data team at Lumora, a B2B SaaS company. I build pipelines and metric views. Business users ask Genie One questions on top of them.

# How I work
- Write SQL first. Use Python only when SQL can't do it.
- Use snake_case for tables, columns, and Python names.
- New tables go in the `lumora_dev` schema. Never write to `lumora` directly.
- Every new table gets a table comment and a comment on each column.
- Explain a change in two or three sentences before you write code for it.

# Ask before you act
- Ask before you drop, overwrite, or rename a table.
- Ask before you run anything that scans more than one year of `usage_events`.
