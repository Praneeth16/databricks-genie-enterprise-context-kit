# Company reporting conventions
- Report all revenue and MRR figures in USD unless the user explicitly asks for another currency.
- Use Lumora's fiscal calendar (fiscal year starts on February 1) for quarterly and annual rollups.
- Always check Genie Ontology definitions and certified Unity Catalog metric views before writing SQL for active customers, MRR, or churn.

# Response style
- Lead with a concise summary table before narrative commentary.
- Include the date window and region filter used in every KPI answer.
- If two workspace assets disagree on a metric definition and neither is certified, flag the conflict and ask which source to use.
